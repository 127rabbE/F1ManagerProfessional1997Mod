# F1 Manager Professional - The 1997 Fix Mod
A mod to fix all the issues in the game.

Full disclosure, I've used AI to try and fix as many issues in the game as possible. I'm not a coder so I've tried to ensure there is as little 'slop' in this as possible.

You can find the manual for the game which you can download and look through, it contains more up to date information about features that are in the game and that work.

The mod will also contain the original games manual however you should use the one I've created first and if you can't find an answer in there, use the original as a fallback.

I've also uploaded a HTML version of the change log. Simply click on it, download it and open it in your browser. It shows everything I've done with AI to the game.

To run the game you will need dosbox-x over at https://dosbox-x.com/
You'll need to open it and do the following once you've downloaded the games folder to play the game.
mount d d:\F1       <- assuming you have placed the folder onto your D drive and renamed it to F1.
D:                  <- this is the letter of the drive, so if it is not D then change it to wherever the game now exists.
f1
